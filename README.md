# 🎓 Student Placement Management System

A web-based Student Placement Management System that helps students discover placement opportunities, check eligibility, apply for jobs, and track application status. The system also provides a dedicated Training & Placement Coordinator portal for managing companies, jobs, applicants, and placement statistics.

## 📌 Project Overview

The Student Placement Management System provides two separate portals:

### 👨‍🎓 Student Portal

Students can:

- Register using their institute email
- Login securely
- Complete and update their profile
- Add academic information and skills
- Add preferred job roles
- Add resume link
- View available placement opportunities
- Check job eligibility automatically
- Apply for eligible jobs
- Prevent duplicate applications
- Track application status

### 👨‍💼 T&P Coordinator Portal

Coordinators can:

- Register and login
- Add companies
- View companies
- Create placement jobs/drives
- Set eligibility criteria
- Specify package, location and deadline
- Define selection process
- View applicants
- Search and filter applicants
- Filter applicants by branch, CGPA and status
- View student information
- Update application status
- Edit jobs
- Close jobs
- View placement statistics

- Interview
- Selected
- Rejected
- Withdrawn
